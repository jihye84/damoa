# 다모아

반 아이들의 생각을 한 화면에 다 모아요.

선생님이 PC에서 수업을 열면 QR 코드가 생기고,
아이들은 태블릿으로 QR을 찍어 자기 이름을 골라 들어옵니다.
선생님이 템플릿을 보내면 아이들이 풀어서 전송하고,
모든 답안이 선생님 화면에 모입니다.

## 화면

- `index.html` — 첫 화면 (선생님 / 학생)
- `teacher.html` — 선생님: 로그인, 반·명렬표, 템플릿 보관함, 수업 진행
- `join.html?c=입장번호` — 학생: 이름 고르기, 풀기, 전송

## 1단계에 들어 있는 것

- 선생님 회원가입·로그인, 학생은 가입 없이 익명 입장
- 반 만들기, 명렬표 붙여 넣기
- 템플릿: 4지선다(자동 채점), 빈 답지(펜), 서술형(타자 + 펜)
- QR·6자리 입장 번호, 입장 현황, 입장 마감, 학생 내보내기
- S펜 필기 (손바닥이 닿아도 선이 안 그어짐), 지우개, 되돌리기
- 분할 보기, 한 명씩 보기, 도장·한마디 돌려주기
- 화면 잠금, 모두 앞을 보세요, 수업 끝내기
- 인앱 브라우저(카카오톡 등)에서 열면 기본 브라우저로 이동

- 학생은 펜이나 손가락으로 지역을 톡 눌러 색칠해요. 지우개로 톡 누르면 색이 지워져요.
- "찾아 칠할 곳"을 정해 두면 칠한 지역이 정답과 똑같을 때 맞음으로 채점해요.

- 경계 자료: 행정동 – 통계청 SGIS(공공누리 제1유형) · vuski/admdongkor ver20261001 (CC BY 4.0) / 나라 – Natural Earth (퍼블릭 도메인)
- 2026년 7월 1일 출범한 전남광주통합특별시를 반영했어요 (16개 시·도).
- 지도 다시 만들기: mapshaper로 단순화·투영 → `tools/recenter.py`(세계·아시아 가운데 맞추기) → `tools/build_maps.py`

## 들어오는 방법 · 반 바꾸기

- 수업마다 **명렬표에서 이름 고르기** 또는 **QR 있는 누구나 · 이름 쓰기**를 고를 수 있어요 (수업 중에도 입장 화면에서 바꿀 수 있어요).
- 누구나 모드에서는 학생이 이름이나 별명(12글자까지)을 쓰고 들어와요. "별명 만들어 줘요"를 누르면 "반짝이는 수달" 같은 별명이 생겨요. 같은 수업에서 같은 이름은 못 써요.
- 이름을 쓰고 들어온 학생은 그 수업에만 있는 손님이라 명렬표에는 남지 않아요.
- 수업 중 화면 왼쪽 위 반 이름을 누르면 **반 바꾸기**: 다른 반 수업을 이어서 하거나 새 QR로 시작해요. 지금 수업은 끝내거나 열어 둘 수 있어요.
- 필요한 SQL: `supabase/05_open_join.sql`

## 작곡 템플릿

- 칸을 톡 누르거나 쭉 끌어서 음을 놓고 ▶로 들어 봐요 (도~높은 도 또는 두 옥타브, 아래에 큰북·작은북 줄).
- 선생님이 앞 마디를 지어 두면 학생은 그 뒤를 **이어 짓기** 해요. 앞부분은 학생이 바꿀 수 없어요.
- 소리는 브라우저가 직접 만들어요 (마림바·피아노·전자음). 음 색은 붐웨커 색이에요.
- 묶음: `library/songs.json` (`python3 tools/gen_songs_lib.py`) — 가락은 저작권이 끝난 옛 동요(작은 별, 비행기, 나비야)의 앞부분만 써요.

## 모양 그림판

- ○△□ 버튼으로 모양을 놓고, 끌어서 옮기고, 네모 손잡이로 크기, 동그란 손잡이로 방향(15도씩)을 바꿔요. 색 19가지, 똑같이 하나 더 · 뒤집기 · 맨 앞/뒤 · 지우기.
- 선생님은 쓸 수 있는 모양을 고르고, 모양을 미리 놓아 둘 수 있어요 (학생이 옮길 수 있음).
- 모양별 개수를 정하면 자동 채점해요 (예: 세모 2개 · 네모 3개).
- 묶음: `library/shapes.json` (`python3 tools/gen_shapes_lib.py`)

## 포트폴리오 (선생님 화면)

- 홈 → 명렬표 칸의 **포트폴리오**: 반을 고르고 학생을 누르면 그 학생이 낸 것이 최근 것부터 카드로 나와요 (도장·한마디·자동 채점 함께).
- 기간(1학기·2학기·이번 달)·종류로 거르고, 카드의 ★로 **대표작**을 달아요. "★ 대표작만"으로 모아 봐요.
- **이 학생 인쇄 / 반 전체 인쇄**: A4에 한 쪽 6장(또는 2장), 학생마다 새 쪽. 인쇄 창에서 "PDF로 저장"도 돼요.
- 명렬표로 들어온 학생만 쌓여요 ("누구나 · 이름 쓰기" 손님은 빠져요).
- **초기화**: 이 학생 또는 반 전체, 모든 기간 또는 고른 기간, ★ 대표작은 남길 수도 있어요. "지우기"라고 써야 지워져요 (되돌릴 수 없음).
- 필요한 SQL: `supabase/06_portfolio.sql` (대표작 별표)

## 수학 도구 템플릿 (`js/w/`)

| 도구 | 하는 일 | 자동 채점 |
|---|---|---|
| 모형 시계 | 바늘을 끌어 시각 만들기 · 시계 보고 시각 쓰기 (30분·5분·1분 단위) | 시각이 맞는지 |
| 십 배열판 · 수 모형 | 동그라미 놓기(가르기는 빨강·파랑) · 백·십·일 모형 놓기 | 개수 · 나타낸 수 |
| 세로셈 | 덧셈·뺄셈·곱셈(두 자리 곱하기는 두 줄), 숫자 패드로 칸 채우기 | 마지막 줄 답 (칸마다 표시) |
| 수직선 | 점 찍기 · 뛰어 세기 화살표 (자연수·분수·소수 눈금) | 찍은 곳 · 도착한 곳과 뛰는 크기 |
| 분수 색칠판 | 원·막대·사각형 조각 칠하기 (여러 개 가능) | 칠한 조각 수 |
| 막대그래프 | 표를 보고 칸을 눌러 막대 쌓기 (한 칸 크기 1·2·5·10) | 막대 높이 (틀린 막대 표시) |
| 점판 | 점을 이어 도형 그리기 | 꼭짓점 수 · 직각삼각형/직사각형/정사각형 · 넓이 |

- 편집기: 새 템플릿 → **수학 도구** → 도구 고르기. 문제 칸을 비우면 문제 글을 자동으로 넣어요.
- 묶음: `library/mathtools.json` (`python3 tools/gen_tools_lib.py`) — 1~5학년 단원별 21묶음.

## 빠른 만들기 · 복사해서 새로

- 홈 → 템플릿 칸 **⚡ 빠른 만들기**: 한 줄에 하나씩 쓰면 알아서 만들어요. 여러 줄이면 한꺼번에 폴더에 넣어요.
  - `8 + 5` 4지선다(보기 자동) · `27 + 35`, `23 × 4` 세로셈 · `3:30`, `2시 15분` 모형 시계 · `3/4` 분수 색칠판
  - `7 = 3 + 4` 가르기 · `9` 십 배열판 · `57` 수 모형 · `질문? 보기, *정답, 보기, 보기` 4지선다 · `…?` 서술형 · 그 밖의 글 빈 답지
  - 오른쪽 목록에서 종류 단추를 눌러 바꿀 수 있어요 (예: 8 + 5를 세로셈으로).
- 미리 보기 창의 **복사해서 새로**: 같은 폴더에 복사본을 만들고, 숫자만 바꾸면 문제 글·이름도 따라 바뀌어요.
- **+ 새 템플릿**은 마지막에 만든 종류로 열려요.
- 수업 중 위쪽 **⚡ 바로 내기**: 써서 바로 보내요 (Ctrl + Enter). 여러 줄이면 여러 장을 보내고, 아이들은 첫 줄 문제부터 풀어요. 만든 문제는 "수업 중 만든 문제" 폴더에 남아요.

## 링크 보내기

- 새 템플릿 → **링크**, 또는 빠른 만들기·바로 내기에서 **주소를 붙여 넣기만** 하면 돼요 (`오늘의 노래 https://youtu.be/…`처럼 앞에 쓴 글은 문제 글이 돼요).
- 유튜브와 구글 문서·슬라이드·설문은 **다모아 화면 안에서** 열려요 (아이들이 앱 밖으로 나가지 않게). 그 밖의 사이트는 큰 **열어 보기** 단추로 새 탭에서 열려요.
- 학생이 열어 봤는지가 답안에 남아요. `http(s)` 주소만 받아요.
